# 2048

HTML, CSS, JavaScript만으로 만든 반응형 2048 퍼즐 게임입니다. 같은 숫자 타일을 합쳐 2048을 만들어 보세요.

## 실행 방법

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 별도 설치나 빌드 과정은 없습니다.

## 조작법

- 키보드: 방향키 또는 `W`, `A`, `S`, `D`
- 모바일: 게임판을 위·아래·왼쪽·오른쪽으로 스와이프
- `되돌리기`: 바로 전 한 수를 취소
- `새 게임`: 점수와 게임판을 초기화

최고 점수는 브라우저의 로컬 저장소에 보관됩니다.
